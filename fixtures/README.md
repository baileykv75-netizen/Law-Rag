# Public Test Fixtures

This directory is reserved for **fully fictional, public-safe test fixtures**.

Allowed future examples:

- synthetic PDF contracts created specifically for Law-Rag;
- synthetic JPG/PNG scan-like documents;
- deliberately designed examples containing known arithmetic/date/entity inconsistencies;
- expected machine-readable outputs for public regression tests.

Do not place real or merely redacted confidential contracts here.

Private professional-review datasets belong in the ignored `benchmark_private/` or another approved ignored local path.
